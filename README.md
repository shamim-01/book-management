## 📖 Project Overview

A **Full-Stack Book Management System** built with the **MERN** stack (MongoDB, Express.js, React.js, Node.js). This application allows users to **manage books**, **borrow/return books**, **write reviews**, and **track statistics** with a beautiful, responsive UI.

### 🌟 Key Features

- 🔐 **JWT Authentication** - Secure Login/Register system
- 📚 **CRUD Operations** - Create, Read, Update, Delete books
- ⭐ **Reviews & Ratings** - Users can rate and review books (1-5 stars)
- 📖 **Borrow & Return** - Borrow books with due date tracking
- 🔍 **Advanced Search** - Search by title, author, genre, price range
- 📊 **Dashboard** - Beautiful statistics with charts
- 🌙 **Dark Mode** - Toggle between light and dark themes
- 📸 **Cover Images** - Book cover images support
- 📱 **Responsive Design** - Fully responsive for all devices

## 🛠️ Tech Stack

### **Frontend**
- **React.js** - UI Library
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **React Router DOM** - Navigation
- **React Icons** - Icons
- **Axios** - HTTP Client

- **Mongoose** - ODM
- **JWT** - Authentication
- **Bcrypt.js** - Password Hashing
- **Cloudinary** - Image Upload

- **MongoDB Atlas** - Cloud Database
